# 동학농민혁명 참여자 후손 판별 스킬 (donghak-descendant-check)

어떤 AI 에이전트(Claude Code / Codex / Hermes 등)에서도 `python donghak.py` 한
줄로 **동학농민혁명(1894) 참여자 명부**를 조회해, 이용자가 참여 인물의 직계
후손인지 판별을 돕는 범용 도구입니다.

> ⚠ **정직한 범위**: 명부 DB는 성씨+이름+지역만 보유합니다. 본관/파(派) 필터는
> 불가능하므로, 이 스킬은 **"후보 명단 추출 + 교차검증 가이드"** 를 제공합니다.
> "후손 확정"을 자동으로 주장하지 않습니다.

## 4. CLI 전체 플래그

| 플래그 | 필수 | 설명 |
|--------|------|------|
| `--surname` | ✅* | 성씨 (예: 백, 이, 김, 변). `*--clan` 으로 대체 가능 |
| `--bonghan` | ❌ | 본관 (예: 수원백씨) — 레포트 표기 |
| `--region` | ❌ | 집성촌/연고 지역 키워드 (예: 거창, 김해) |
| `--branch` | ❌ | 파(派) (예: 정신재공파) |
| `--ancestor` | ❌ | 부모님 확인 조상 실명 (예: 백도홍) — 정확 매칭 |
| `--clan` | ❌ | `clans.json` 프리셋 키 (성씨/지역 기본값 자동채움, 항렬 데이터 로드) |
| `--pages` | ❌ | 최대 처리 페이지 (0=전체). 상한 도달 시 커버리지 경고 |
| `--lit` | ❌ | 로컬 문헌/논문 코퍼스 폴더 (미등록 후보 추가 발굴) |
| `--web` | ❌ | 웹 학술검색 사용 (`.env` 의 `DONGHAK_LIT_API_URL`+`KEY` 필요) |
| `--json` | ❌ | JSON 출력 |
| `--csv` | ❌ | CSV 출력 |
| `--out` | ❌ | 결과 파일 저장 경로 |
| `--no-cache` | ❌ | 캐시 미사용(항상 재다운로드) |

## 5. 레퍼런스 성씨 (프리셋 예시)

`clans.json` 에 포함된 샘플입니다. **어떤 성씨든 자유 입력 가능**하며, 이들은
편의 프리셋일 뿐입니다.

| 프리셋 키 | 성씨 | 대표 연고 | 규모 |
|-----------|------|-----------|------|
| `수원백씨` | 백 | 거창·하동·진주 | rare |
| `경주이씨` | 이 | 경주·성주 | common |
| `김해김씨` | 김 | 김해·밀양 | common |
| `초계변씨` | 변 | 초계·거창 | mid |

`common` 규모 성씨는 결과가 수천 건일 수 있으니 `--region` 필터를 권장합니다.

---

## 5.5 항렬(항렬)·종파(파) 엔진

`clans.json` 의 `generations`(항렬 순환표)를 읽어, 추출된 참여자 이름에 항렬 자가
포함되면 **세대(`gen_index`)를 자동 배정**하고 보고서에 "항렬 기반 세대 배열" 섹션을
추가합니다. 이를 통해 다비드님 같은 이용자가 **같은 항렬선/파에 속하는 후보**를
세대순으로 정렬해 볼 수 있습니다.

- `--clan <키>` 로 해당 본관의 항렬 데이터를 로드합니다.
- `branches`(파 트리)는 `clans.json` 에 구조로 보관되며, 종중 족보 검증용 참고자료로 씁니다.
- ⚠ **데이터 정직성**: `clans.json` 의 `generations` 는 **예시(미확정)** 입니다. 실제
  수원백씨 항렬 순환표는 종중 족보에서 확인 후 교체해야 합니다. (다비드 33세 형/亨 돌림은
  본인 확인됨) 비어 있으면 해당 섹션은 표시되지 않습니다.

---

## 5.6 문헌·논문 모듈 (미등록 참여자 발굴)

공식 DB(cdpr.go.kr)에 **등록되지 않은** 참여자가 문헌/논문/족보에 있을 수 있습니다.
이를 보완하는 두 가지 소스:

1. **로컬 코퍼스 (기본, 제로의존)**
   - `--lit <폴더>`: 논문/족보/향토사 텍스트(`.txt/.md/.html/.csv`)를 재귀 스캔해
     성씨+이름 후보를 추출. 공식 DB에 없는 이름은 "문헌/논문에서 추가 발굴" 섹션에 표시.
   - 독립 CLI `donghak_lit.py` 로도 실행 가능.
2. **웹 학술검색 (선택, 키 필요)**
   - `--web` + 환경변수 `DONGHAK_LIT_API_URL`( `{q}` 를 성씨로 치환),
     `DONGHAK_LIT_API_KEY` 설정 시에만 동작. 미설정이면 관여하지 않음.
   - 키는 `.env` 에 보관 (`.gitignore` 대상, 하드코딩 금지).

## 6. 실행 예시

```bash
# 수원백씨, 거창 연고로 후보 탐색
python donghak.py --clan 수원백씨 --region 거창

# 김해김씨 전수 중 김해 연고만 (상한 50페이지)
python donghak.py --surname 김 --region 김해 --pages 50

# 조상 실명으로 정확 매칭
python donghak.py --surname 백 --ancestor 백도홍

# 기계 가독 출력
python donghak.py --clan 수원백씨 --region 거창 --json

# 항렬 섹션 포함 (수원백씨 프리셋)
python donghak.py --surname 백 --clan 수원백씨

# 문헌 코퍼스에서 미등록 후보 발굴
python donghak.py --surname 백 --lit ./corpus
python donghak_lit.py --corpus ./corpus --surname 백   # 독립 CLI
```

---

## 7. 한계 & 정직성

- DB는 성씨+이름+지역만 → 본관/파는 추론 불가. 동명이인·이본관 혼재 가능.
- "후보 0명" ≠ "참여 안 함". 미신청 / 이명 등록 / 실명 미상 가능성 열림.
- 사이트 구조 변경 시 파싱 코드 수정 필요 (공식 API 없음).
- 최종 확인은 가족(부모님) → 종중 족보 → 기념재단 교차검증 필요.
