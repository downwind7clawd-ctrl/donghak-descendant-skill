# 작업 로그 — donghak-descendant-skill

## [2026-08-28] 맥거핀: D 확장 — 세대 역산 엔진 + clan 항렬표 자가수집 + 가족 확인 워크플로

### 발신자: 다비드
- 익명 지인(이씨) 체크 중 "경주이씨 항렬을 조회해 항렬·연령 역산으로 확률 높은 사람을 추적해야 옳다" 지시.
- clan 항렬표는 에이전트가 직접 검색·확보하고 지침에 명시할 것 지시 (중앙 DB 없음).
- 지인 출생년도(예: 1981), 부친 생년(예: 1946) 제공.
- "항렬 밴드 부합 고점수" 추측에 대해 "조상과 2세대 차이인데 같은 항렬이라니?" 반론 → 항렬 점수 과대평가 지적.
- "증조할아버지 실명 모르는 경우 많음 → 에이전트는 확률 높은 인물 나열 + 집안 확인" 지시.

### 작업 (맥거핀)
1. **세대 역산 엔진** (`donghak.py`)
   - `participant_band(birth_year, base=1880, interval=30)`: 앵커 생년 → 참여자까지 세대 수(gen_gap) + 항렬 밴드(36~44세).
   - `score_candidates()`: (항렬 세대 부합 + 연고지 + 조상실명 유사도) 점수화.
   - `--birth-year`, `--ancestor-birth-year`(조상 앵커 → interval 자동 추정), `--gen-interval` 플래그 추가.
   - `KINSHIP` 맵: 1=아버지, 2=할아버지, 3=증조할아버지 자동 표기.
2. **clan 항렬표 자가수집**
   - 경주이씨 대동항렬(1868 고종 제정, 35~70세) 웹 참고 수집 → `clans.json` 입력.
   - SKILL.md에 "clan 항렬표·파 직접 확보 (에이전트 필수)" 절차 명시 (임의 날조 금지).
3. **항렬 점수 정보성 조정** (다비드 지적 반영)
   - 혈통 근거 아님을 명시, 가중 +2 → +1 하향.
4. **가족 확인 워크플로**
   - 보고서에 "위 후보 중 집안에서 들은 적 있는 이름이 있는지 가족 확인" 안내 추가.
   - SKILL.md 절차 6, README 한계에 명시.
5. **문서 갱신**: SKILL.md, README.md, 설계 스펙(Phase 2.5/2.6, CLI, 한계, 변경이력), 계획 문서(변경이력).
6. **PII 정리**: 지인/부친 실명 및 정확 생년을 문서에서 삭제(익명화). 코드 내 `--ancestor` 라벨이 하드코딩명으로 고정되던 버그 수정(실제 입력명 사용).
